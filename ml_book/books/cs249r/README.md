# CS249r release files

Official PDF and EPUB releases of Harvard CS249r *Machine Learning Systems*. Part XV of the book (`books/systems/`) links to them, and they are copied into the built site. They are gitignored. Re-download with `bash scripts/fetch_cs249r.sh`.

| File | Release |
|---|---|
| `Machine-Learning-Systems-Vol1.pdf` / `.epub` | vol1-v0.8.0 |
| `Machine-Learning-Systems-Vol2.pdf` / `.epub` | vol2-v0.3.0 (preview) |

The page numbers in `systems/02_cs249r_vol1.qmd` and `03_cs249r_vol2.qmd` match these exact releases. When a newer release comes out, update the tags in the fetch script and re-check the page links.
