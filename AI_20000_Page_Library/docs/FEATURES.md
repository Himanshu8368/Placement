# Website Features & Enhancements

This document describes all the features and enhancements available on the AI & Machine Learning Compendium website.

## 🎯 Core Features

### 1. **Reading Progress Bar**
- A visual progress bar at the top of the page shows your reading progress
- Updates automatically as you scroll
- Helps you track your position in long articles

### 2. **Reading Time Estimates**
- Automatically calculates and displays estimated reading time for each page
- Based on average reading speed (200 words per minute)
- Appears below the page title

### 3. **Keyboard Shortcuts**
Press `?` to see all available keyboard shortcuts:

- `/` or `s` - Focus search bar
- `?` - Show/hide keyboard shortcuts
- `Esc` - Close dialogs and modals
- `g h` - Go to homepage
- `g n` - Navigate to next page
- `g p` - Navigate to previous page

### 4. **Print-Friendly Pages**
- Click the "Print Page" button on any article
- Optimized print stylesheet removes navigation and focuses on content
- Clean, readable output for offline reading

### 5. **Enhanced Typography**
- Improved line spacing and font sizes for better readability
- Justified text for professional appearance
- Better heading hierarchy and spacing
- Enhanced code block styling with shadows

### 6. **PDF Viewer**
- Embedded PDF viewer with download and open options
- Responsive design that works on all devices
- Toolbar with quick actions

### 7. **Dark/Light Mode**
- Toggle between dark and light themes
- Preference is saved automatically
- Reduces eye strain for extended reading

### 8. **Full-Text Search**
- Search across all 20,000+ pages
- Instant search suggestions
- Highlighted search results

### 9. **Navigation Features**
- Hierarchical navigation sidebar
- Expandable sections
- Breadcrumb navigation
- Table of contents integration

### 10. **Code Block Enhancements**
- Copy button on every code block
- Syntax highlighting
- Line numbers support
- Annotated code blocks

### 11. **Bookmarking System** ⭐ NEW
- Save favorite pages for quick access
- Bookmark button on every page
- Visual feedback when bookmarking
- Bookmarks saved in browser (localStorage)
- Persistent across sessions

### 12. **Reading History** ⭐ NEW
- Automatically tracks pages you visit
- Shows "Recently Read" widget on homepage
- Displays last 3 recently read pages
- Tracks reading progress percentage
- Keeps history of up to 50 pages

### 13. **Related Pages Suggestions** ⭐ NEW
- Automatically detects related content
- Shows up to 5 related pages at bottom of articles
- Based on section and part relationships
- Visual widget with icons
- Helps discover related topics

### 14. **Glossary Popup System** ⭐ NEW
- Automatically highlights 50+ technical terms
- Hover over terms to see definitions
- Smart tooltip positioning
- Non-intrusive (doesn't affect code blocks)
- Includes terms like: CNN, Transformer, Backpropagation, LSTM, GAN, etc.

### 15. **Multi-Format File Viewer** ⭐ NEW
- **PDF Files** (.pdf) - Embedded PDF viewer with download option
- **Text Files** (.txt) - Readable text display with copy to clipboard
- **PowerPoint** (.ppt, .pptx) - Microsoft Office Online viewer
- **Word Documents** (.doc, .docx) - Online document viewer
- **Excel Files** (.xls, .xlsx) - Online spreadsheet viewer
- Automatic file detection and viewer page generation
- Download and open options for all file types
