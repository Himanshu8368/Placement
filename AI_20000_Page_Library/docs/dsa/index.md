## Data Structures & Algorithms (DSA)

This collection will cover the core foundations of **data structures and algorithms**, with a focus on interview‑ready and production‑ready understanding.

Planned high‑level sections (each as a small number of rich pages rather than many tiny files):

- **Foundations** – complexity, notation, problem‑solving patterns
- **Core Data Structures** – arrays, linked lists, stacks, queues, hash tables
- **Trees & Graphs** – BSTs, heaps, tries, graph representations and traversals
- **Algorithms** – sorting, searching, greedy, divide‑and‑conquer, dynamic programming
- **Practice & Patterns** – common patterns and representative problems

As you add content, we can map each section into a few well‑structured markdown pages to keep the file count low.
