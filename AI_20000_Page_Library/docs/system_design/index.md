## System Design Collection

This collection will focus on **practical system design** concepts for scalable, reliable, and maintainable systems.

Planned high‑level sections:

- **Foundations** – requirements, SLAs, scalability, consistency, availability
- **Core Building Blocks** – load balancers, caches, databases, message queues, storage
- **Design Patterns** – microservices, event‑driven, CQRS, sharding, replication
- **Case Studies** – designing services like URL shortener, news feed, chat, etc.
- **Operational Concerns** – monitoring, alerting, capacity planning, reliability

We will keep this organized into a small set of comprehensive markdown pages instead of many tiny files.
