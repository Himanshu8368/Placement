    Introduction to Loss Functions¶

    What is a Loss Function?¶

    A loss function (or cost function) measures how well our model's predictions match the actual values.

    Terminology: - Loss function L(ŷ, y): Error for a single example - Cost function J(w): Average loss over all examples

    Cost = Average of all losses
J(w) = (1/m) Σᵢ₌₁ᵐ L(ŷ⁽ⁱ⁾, y⁽ⁱ⁾)

    Why Do We Need Loss Functions?¶

    Purpose: 1. Quantify error: How wrong are our predictions? 2. Guide optimization: What direction to move parameters? 3. Compare models: Which model is better?

    The learning process: 

    1. Choose loss function L
2. Compute predictions ŷ = f(x; w)
3. Compute cost J(w) = average loss
4. Minimize J(w) by adjusting w

    Desirable Properties¶

    A good loss function should be: 1. Non-negative: L(ŷ, y) ≥ 0 2. Zero at perfect prediction: L(y, y) = 0 3. Differentiable: Can compute gradients 4. Convex (ideally): One global minimum 5. Robust: Not too sensitive to outliers (sometimes)

    Visual Intuition¶

        Loss
    │
    │      /
    │     /
    │    /
    │   /
    │  /
    │ /
    │/___________  Correct prediction
    │
    │  (Error = 0)
    │
    └──────────────────── Prediction Error

    Good loss: Small when close, large when far

    Mean Squared Error (MSE)¶

    Definition¶

    Mean Squared Error is the average of squared differences between predictions and actual values.

    For single example: 

    L_MSE(ŷ, y) = (ŷ - y)²

    For all examples (cost function): 

    J_MSE(w) = (1/m) Σᵢ₌₁ᵐ (ŷ⁽ⁱ⁾ - y⁽ⁱ⁾)²

    Sometimes with 1/2 factor (simplifies derivative): 

    J_MSE(w) = (1/2m) Σᵢ₌₁ᵐ (ŷ⁽ⁱ⁾ - y⁽ⁱ⁾)²

    Matrix Form¶

    J_MSE(w) = (1/2m) ||Xw - y||²
         = (1/2m) (Xw - y)ᵀ(Xw - y)

    Why "Squared"?¶

    Squaring has several effects:

    1. Makes errors positive: (-3)² = 9, same as (3)²
    2. Penalizes large errors more:
    3. Error 1 → Loss 1
    4. Error 2 → Loss 4
    5. Error 3 → Loss 9
    6. Smooth and differentiable: No corners or kinks
    7. Convex: Guarantees single global minimum

    Visual Representation¶

        Loss
    │
  9 │                   ●  (error=3, loss=9)
    │
  4 │         ●            (error=2, loss=4)
    │
  1 │   ●                  (error=1, loss=1)
    │
  0 │●                     (error=0, loss=0)
    │
    └─────────────────────────── Prediction Error
    0     1     2     3

    Parabolic shape - penalizes outliers heavily

    Gradient Derivation¶

    For linear regression: ŷ = wᵀx

    Step 1: Loss for one example 

    L(ŷ, y) = (ŷ - y)²

    Step 2: Derivative with respect to prediction 

    ∂L/∂ŷ = 2(ŷ - y)

    Step 3: Chain rule for weights 

    ∂L/∂wⱼ = ∂L/∂ŷ · ∂ŷ/∂wⱼ
       = 2(ŷ - y) · xⱼ

    Step 4: Average over all examples 

    ∂J/∂wⱼ = (1/m) Σᵢ₌₁ᵐ 2(ŷ⁽ⁱ⁾ - y⁽ⁱ⁾) · x⁽ⁱ⁾ⱼ

    With 1/2 factor: 

    ∂J/∂wⱼ = (1/m) Σᵢ₌₁ᵐ (ŷ⁽ⁱ⁾ - y⁽ⁱ⁾) · x⁽ⁱ⁾ⱼ

    Python Implementation¶

    import numpy as np
import matplotlib.pyplot as plt

def mse_loss(y_true, y_pred):
    """
    Mean Squared Error loss

    Args:
        y_true: Actual values (m,)
        y_pred: Predicted values (m,)

    Returns:
        MSE loss (scalar)
    """
    return np.mean((y_pred - y_true) ** 2)

def mse_gradient(X, y_true, y_pred):
    """
    Gradient of MSE with respect to weights

    Args:
        X: Feature matrix (m × n)
        y_true: Actual values (m,)
        y_pred: Predicted values (m,)

    Returns:
        Gradient vector (n,)
    """
    m = len(y_true)
    return (1/m) * X.T @ (y_pred - y_true)

y_pred = np.array([2.5, 3.8, 5.2, 3.9, 5.1])

print(f"MSE: {mse:.4f}")

    Properties of MSE¶

    Advantages: ✅ Smooth and differentiable: Easy to optimize ✅ Convex: One global minimum ✅ Closed-form solution: Normal equation exists ✅ Penalizes large errors: Good for most cases ✅ Statistical interpretation: Maximum likelihood under Gaussian noise

    Disadvantages: ❌ Sensitive to outliers: Large errors dominate ❌ Different units: Squared units (hard to interpret) ❌ Not robust: Few outliers can ruin the model

    Example: Outlier Sensitivity¶

    Mean Absolute Error (MAE)¶

    Definition¶

    Mean Absolute Error is the average of absolute differences between predictions and actual values.

    For single example: 

    L_MAE(ŷ, y) = |ŷ - y|

    For all examples: 

    J_MAE(w) = (1/m) Σᵢ₌₁ᵐ |ŷ⁽ⁱ⁾ - y⁽ⁱ⁾|

    Visual Representation¶

        Loss
    │
  3 │             ╱●  (error=3, loss=3)
    │           ╱
  2 │         ╱●      (error=2, loss=2)
    │       ╱
  1 │     ╱●          (error=1, loss=1)
    │   ╱
  0 │ ●               (error=0, loss=0)
    │╱
    └─────────────────────────── Prediction Error
    0     1     2     3

    V-shape - linear penalty

    Comparison with MSE¶

    Error  | MSE Loss | MAE Loss | MSE/MAE Ratio
-------|----------|----------|---------------
  0.1  |   0.01   |   0.1    |    0.1
  0.5  |   0.25   |   0.5    |    0.5
  1.0  |   1.00   |   1.0    |    1.0
  2.0  |   4.00   |   2.0    |    2.0
  5.0  |  25.00   |   5.0    |    5.0
 10.0  | 100.00   |  10.0    |   10.0

    Key observation: MSE grows quadratically, MAE grows linearly.

    Gradient¶

    Problem: Absolute value is not differentiable at 0!

    ∂|x|/∂x = { +1  if x > 0
          { -1  if x < 0
          { undefined if x = 0

    In practice: We use the sign function:

    ∂J_MAE/∂wⱼ = (1/m) Σᵢ₌₁ᵐ sign(ŷ⁽ⁱ⁾ - y⁽ⁱ⁾) · x⁽ⁱ⁾ⱼ

    Where: 

    sign(x) = { +1  if x > 0
          {  0  if x = 0
          { -1  if x < 0

    Python Implementation¶

    Properties of MAE¶

    Advantages: ✅ Robust to outliers: Linear penalty ✅ Interpretable: Same units as target variable ✅ Median estimate: Minimizer is the median ✅ Balanced: All errors weighted equally

    Disadvantages: ❌ Not differentiable at zero: Optimization challenges ❌ No closed-form solution: Must use iterative methods ❌ Slower convergence: Constant gradient magnitude ❌ Not smooth: Can't use some optimization methods

    Example: Outlier Robustness¶

    Training with MAE¶

    def train_with_mae(X, y, alpha=0.01, num_iterations=1000):
    """Train linear regression with MAE loss"""
    m, n = X.shape
    w = np.zeros((n, 1))
    losses = []

    for i in range(num_iterations):
        # Predictions
        y_pred = X @ w

        # MAE gradient
        gradient = (1/m) * X.T @ np.sign(y_pred - y)

        # Update
        w = w - alpha * gradient.reshape(-1, 1)

        # Record loss
        loss = np.mean(np.abs(y_pred - y))
        losses.append(loss)

    return w, losses

# Example usage

X = 2 * np.random.rand(m, 1)

print(f"Trained weights (MAE):")
print(f"w0: {w_mae[0][0]:.4f}")
print(f"w1: {w_mae[1][0]:.4f}")

    Root Mean Squared Error (RMSE)¶

    Definition¶

    Root Mean Squared Error is the square root of MSE.

    RMSE = √MSE = √[(1/m) Σᵢ₌₁ᵐ (ŷ⁽ⁱ⁾ - y⁽ⁱ⁾)²]

    Why Take the Square Root?¶

    Problem with MSE: Units are squared (e.g., dollars²) Solution: Take square root to get original units (dollars)

    Example: 

    Predicting house prices in $1000s
MSE  = 4.0 (units: $1000²) ← Hard to interpret!
RMSE = 2.0 (units: $1000)  ← "Average error is $2000"

    Properties¶

    Same as MSE for optimization: 

    min MSE  ⟺  min RMSE

    Because square root is monotonic increasing.

    But different values: 

    If MSE = 4.0  →  RMSE = 2.0
If MSE = 9.0  →  RMSE = 3.0

    When to Use RMSE¶

    Use RMSE for: - Reporting: More interpretable than MSE - Comparing models: Same scale as target variable - Evaluation metrics: Standard in many competitions

    Use MSE for: - Training: Simpler gradient computation - Theory: Cleaner mathematical properties

    Python Implementation¶

    def rmse_loss(y_true, y_pred):
    """Root Mean Squared Error"""
    mse = np.mean((y_pred - y_true) ** 2)
    return np.sqrt(mse)

# Example
y_true = np.array([2, 4, 5, 4, 5])
y_pred = np.array([2.5, 3.8, 5.2, 3.9, 5.1])

mse = mse_loss(y_true, y_pred)
rmse = rmse_loss(y_true, y_pred)

print(f"MSE:  {mse:.4f}")
print(f"RMSE: {rmse:.4f}")

    Huber Loss¶

    Definition¶

    Huber loss combines MSE and MAE - it's quadratic for small errors, linear for large errors.

    L_δ(ŷ, y) = { ½(ŷ - y)²              if |ŷ - y| ≤ δ
            { δ|ŷ - y| - ½δ²         if |ŷ - y| > δ

    Where δ is a hyperparameter (typically δ = 1.0).

    Visual Representation¶

        Loss
    │
    │          ╱  (Linear for large errors)
    │        ╱
    │      ╱
    │    ╱
    │   ╱╲  (Quadratic for small errors)
    │  ╱  ╲
    │ ╱    ╲
    │╱      ╲
    └─────────────────── Prediction Error
        -δ   0   +δ

    Why Huber Loss?¶

    Best of both worlds: - Small errors: Smooth (like MSE) → good for optimization - Large errors: Linear (like MAE) → robust to outliers

    Comparison Table¶

    Error  | MSE  | MAE  | Huber(δ=1)
-------|------|------|------------
  0.5  | 0.25 | 0.5  |   0.125
  1.0  | 1.00 | 1.0  |   0.5
  2.0  | 4.00 | 2.0  |   1.5
  5.0  | 25.0 | 5.0  |   4.5
 10.0  |100.0 | 10.0 |   9.5

    For errors ≤ δ: Huber ≈ ½×MSE For errors > δ: Huber ≈ MAE

    Python Implementation¶

    def huber_loss(y_true, y_pred, delta=1.0):
    """
    Huber loss

    Args:
        y_true: Actual values
        y_pred: Predicted values
        delta: Threshold for switching from quadratic to linear

    Returns:
        Huber loss (scalar)
    """
    error = y_pred - y_true
    abs_error = np.abs(error)

    # Quadratic for small errors
    quadratic = 0.5 * error ** 2

    # Linear for large errors
    linear = delta * abs_error - 0.5 * delta ** 2

    # Choose based on error magnitude
    loss = np.where(abs_error <= delta, quadratic, linear)

    return np.mean(loss)

def huber_gradient(X, y_true, y_pred, delta=1.0):
    """Gradient of Huber loss"""
    m = len(y_true)
    error = y_pred - y_true
    abs_error = np.abs(error)

    # Gradient is error for small, sign*delta for large
    grad_per_example = np.where(
        abs_error <= delta,
        error,
        delta * np.sign(error)
    )

    return (1/m) * X.T @ grad_per_example

    Training with Huber Loss¶

    def train_with_huber(X, y, alpha=0.01, delta=1.0, num_iterations=1000):
    """Train linear regression with Huber loss"""
    m, n = X.shape
    w = np.zeros((n, 1))
    losses = []

    for i in range(num_iterations):
        y_pred = X @ w

        # Huber gradient
        gradient = huber_gradient(X, y, y_pred, delta).reshape(-1, 1)

        # Update
        w = w - alpha * gradient

        # Record loss
        loss = huber_loss(y, y_pred, delta)
        losses.append(loss)

    return w, losses

    Choosing δ¶

    Small δ (e.g., 0.1): - More like MAE - Very robust to outliers - Slower convergence

    Large δ (e.g., 10.0): - More like MSE - Less robust to outliers - Faster convergence

    Typical value: δ = 1.0 is a good default.

    # Visualize loss landscape for simple case
def compute_losses_2d(w0_range, w1_range, X, y):
    """Compute loss for grid of weight values"""
    mse_losses = np.zeros((len(w0_range), len(w1_range)))
    mae_losses = np.zeros((len(w0_range), len(w1_range)))
    huber_losses = np.zeros((len(w0_range), len(w1_range)))

    for i, w0 in enumerate(w0_range):
        for j, w1 in enumerate(w1_range):
            w = np.array([[w0], [w1]])
            y_pred = X @ w

            mse_losses[i, j] = np.mean((y_pred - y) ** 2)
            mae_losses[i, j] = np.mean(np.abs(y_pred - y))
            huber_losses[i, j] = huber_loss(y, y_pred, delta=1.0)

    return mse_losses, mae_losses, huber_losses

    Why We Use Different Losses¶

    1. Data Characteristics¶

    When data has outliers: - Use MAE or Huber - MSE will fit outliers, ruining the model for normal points

    When data is clean (no outliers): - Use MSE - Faster convergence, smoother optimization

    Example scenario: Predicting housing prices - If dataset has a few luxury mansions (outliers) → MAE - If dataset is homogeneous → MSE

    2. Domain Requirements¶

    Financial applications: - Large errors may be catastrophic → Use MSE (penalizes large errors) - Example: Fraud detection (false negatives are very costly)

    Forecasting applications: - Want balanced errors → Use MAE - Example: Sales forecasting (over/under predictions equally bad)

    Medical applications: - Underestimation dangerous → Asymmetric loss - Example: Drug dosage (underdose worse than overdose)

    3. Statistical Interpretation¶

    MSE minimizer = Mean: 

    argmin Σ(ŷ - yᵢ)²  →  ŷ = mean(y)
   ŷ

    MAE minimizer = Median: 

    argmin Σ|ŷ - yᵢ|  →  ŷ = median(y)
   ŷ

    Why this matters: - Mean sensitive to outliers - Median robust to outliers

    4. Optimization Considerations¶

    MSE: ✅ Smooth gradient ✅ Closed-form solution ✅ Fast convergence ❌ Can be dominated by outliers

    MAE: ❌ Non-smooth at zero ❌ No closed-form solution ❌ Slower convergence ✅ Robust

    Huber: ✅ Smooth gradient ✅ Reasonably robust ✅ Good convergence ❌ No closed-form ❌ Extra hyperparameter δ

    5. Interpretability¶

    MSE: - Units are squared → Hard to interpret - "Average squared error is 25 dollars²" ← What does this mean?

    MAE: - Same units as target → Easy to interpret - "Average error is 5 dollars" ← Clear!

    RMSE: - Same units as target → Easy to interpret - Square root of MSE

    6. Custom Losses¶

    Sometimes standard losses aren't enough!

    Asymmetric losses (over/under predictions different costs): 

    def asymmetric_loss(y_true, y_pred, over_cost=1.0, under_cost=2.0):
    """Penalize under-predictions more heavily"""
    error = y_pred - y_true
    loss = np.where(
        error >= 0,  # Over-prediction
        over_cost * error ** 2,
        under_cost * error ** 2  # Under-prediction
    )
    return np.mean(loss)

    Quantile loss (predict specific quantile, not mean): 

    def quantile_loss(y_true, y_pred, quantile=0.9):
    """Loss for quantile regression"""
    error = y_true - y_pred
    loss = np.where(
        error >= 0,
        quantile * error,
        (quantile - 1) * error
    )
    return np.mean(loss)

    Probabilistic Interpretation¶

    Maximum Likelihood Estimation¶

    Loss functions can be derived from probability distributions!

    General principle: 

    Minimize loss = Maximize likelihood

    MSE and Gaussian Distribution¶

    Assumption: Errors are normally distributed

    y = wᵀx + ε
ε ~ N(0, σ²)

    This means: 

    p(y | x, w) = (1/√(2πσ²)) exp(-(y - wᵀx)² / (2σ²))

    Log-likelihood for all examples: 

    log L(w) = Σᵢ log p(y⁽ⁱ⁾ | x⁽ⁱ⁾, w)
         = Σᵢ [constant - (y⁽ⁱ⁾ - wᵀx⁽ⁱ⁾)² / (2σ²)]

    Maximizing log-likelihood = Minimizing squared error!

    max log L(w)  ⟺  min Σ(y - wᵀx)²

    Conclusion: If errors are Gaussian → MSE is optimal!

    MAE and Laplace Distribution¶

    Assumption: Errors follow Laplace distribution (double exponential)

    p(ε) = (1/2b) exp(-|ε|/b)

    Log-likelihood: 

    log L(w) = Σᵢ [constant - |y⁽ⁱ⁾ - wᵀx⁽ⁱ⁾|/b]

    Maximizing log-likelihood = Minimizing absolute error!

    max log L(w)  ⟺  min Σ|y - wᵀx|

    Conclusion: If errors follow Laplace → MAE is optimal!

    Choosing Based on Data Distribution¶

    If you know the error distribution: - Gaussian errors → MSE - Laplace errors → MAE - Heavy-tailed errors → Huber or robust methods

    In practice: Often don't know distribution - Try both MSE and MAE - Use cross-validation to choose - Look at residual distribution

    Preview: Binary Classification Losses¶

    While this section focuses on regression, here's a quick preview:

    0-1 Loss (counting mistakes): 

    L(ŷ, y) = { 0  if ŷ = y
          { 1  if ŷ ≠ y
    Problem: Not differentiable!

    Logistic Loss (cross-entropy): 

    L(ŷ, y) = -[y log(ŷ) + (1-y) log(1-ŷ)]
    Where ŷ = σ(wᵀx) is probability.

    Hinge Loss (SVM): 

    L(ŷ, y) = max(0, 1 - y·ŷ)

    Choosing the Right Loss¶

    Practical Guidelines¶

    1. Start with MSE: - Standard choice - Works well in most cases - Easy to optimize

    2. Switch to MAE if: - You have outliers - Want robust predictions - Don't mind slower convergence

    3. Use Huber if: - Have some outliers but not many - Want smooth optimization - Need balance between MSE and MAE

    4. Use custom loss if: - Domain-specific requirements - Asymmetric costs - Special constraints

    Example Decision Tree¶

    Do you have outliers?
├─ No → MSE
└─ Yes
   ├─ Many outliers (>10%) → MAE
   ├─ Few outliers (<10%) → Huber
   └─ Not sure → Try both, use validation set

    Performance Comparison Code¶

    import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression, HuberRegressor

def compare_losses(X, y, X_test=None, y_test=None):
    """Compare different loss functions"""

    # Train models
    models = {
        'MSE': LinearRegression(),
        'Huber': HuberRegressor(epsilon=1.5),
    }

    results = {}

    for name, model in models.items():
        # Fit
        model.fit(X, y)

        # Predict
        y_pred_train = model.predict(X)

        # Metrics on training set
        train_mse = np.mean((y_pred_train - y) ** 2)
        train_mae = np.mean(np.abs(y_pred_train - y))
        train_rmse = np.sqrt(train_mse)

        results[name] = {
            'model': model,
            'train_mse': train_mse,
            'train_mae': train_mae,
            'train_rmse': train_rmse,
        }

        # If test set provided
        if X_test is not None and y_test is not None:
            y_pred_test = model.predict(X_test)
            test_mse = np.mean((y_pred_test - y_test) ** 2)
            test_mae = np.mean(np.abs(y_pred_test - y_test))
            test_rmse = np.sqrt(test_mse)

            results[name]['test_mse'] = test_mse
            results[name]['test_mae'] = test_mae
            results[name]['test_rmse'] = test_rmse

    # Print comparison
    print("\n" + "="*60)
    print("MODEL COMPARISON")
    print("="*60)
    print(f"{'Model':<15} {'Train MSE':<12} {'Train MAE':<12} {'Train RMSE':<12}")
    print("-"*60)

    for name, res in results.items():
        print(f"{name:<15} {res['train_mse']:<12.4f} {res['train_mae']:<12.4f} {res['train_rmse']:<12.4f}")

    if 'test_mse' in results['MSE']:
        print("\n" + "="*60)
        print("TEST SET PERFORMANCE")
        print("="*60)
        print(f"{'Model':<15} {'Test MSE':<12} {'Test MAE':<12} {'Test RMSE':<12}")
        print("-"*60)

        for name, res in results.items():
            print(f"{name:<15} {res['test_mse']:<12.4f} {res['test_mae']:<12.4f} {res['test_rmse']:<12.4f}")

    return results

# Example usage
np.random.seed(42)
X_train = 2 * np.random.rand(100, 1)
y_train = 4 + 3 * X_train.ravel() + np.random.randn(100)

# Add a few outliers
outlier_indices = [5, 15, 25]
y_train[outlier_indices] += 20

X_test = 2 * np.random.rand(20, 1)
y_test = 4 + 3 * X_test.ravel() + np.random.randn(20)

results = compare_losses(X_train, y_train, X_test, y_test)

    2. Standard choice, smooth, closed-form solution

    { δ|ŷ-y|-½δ²  if |ŷ-y| > δ

    13. MAE ↔ Laplace errors
