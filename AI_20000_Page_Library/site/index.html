    🔍 Features¶

    Core Features¶

    • Full-text search across all 20,000 pages
    • Hierarchical navigation - Browse by Part → Section → Chapter
    • MathJax support for mathematical equations
    • Mobile-responsive design
    • Dark/Light mode toggle
    • PDF viewer - Embedded PDF viewing with download options

    Reading Enhancements¶

    • Reading progress bar - Track your reading position
    • Reading time estimates - Know how long each article takes
    • Reading history - See your recently read pages (last 3 on homepage)
    • Bookmarking system - Save favorite pages for quick access

    Navigation & Discovery¶

    • Related pages suggestions - Discover related content automatically
    • Glossary popup system - Hover over terms to see definitions (50+ terms)
    • Keyboard shortcuts - Press ? to see all shortcuts
    • Enhanced navigation - Breadcrumbs, table of contents, tracking

    Content Features¶

    • Print-friendly pages - Optimized for printing and PDF export
    • Enhanced typography - Better readability and spacing
    • Code block enhancements - Copy buttons, syntax highlighting
    • Interactive elements - Tooltips, smooth animations

    File Viewing Support¶

    • PDF Files (.pdf) - Embedded PDF viewer with download
    • Text Files (.txt) - Readable text display with copy option
    • PowerPoint (.ppt, .pptx) - Online viewer for presentations
    • Word Documents (.doc, .docx) - Online viewer for documents
    • Excel Files (.xls, .xlsx) - Online viewer for spreadsheets

    📖 How to Use¶

    1. Browse by Collection: Use the top navigation tabs or the links above to choose AI, DSA, or System Design
    2. Search: Use the search bar at the top to find specific topics (or press /)
    3. Direct Links: Inside each collection, use the sidebar to jump directly to sections and chapters
    4. Bookmark Pages: Click the bookmark button to save pages for later
    5. View Related Content: Scroll to the bottom of any article to see related pages
    6. Learn Terms: Hover over highlighted terms to see glossary definitions
    7. Track Progress: See your reading history on the homepage
    8. Keyboard Shortcuts: Press ? to see all available shortcuts
