CHAPTER REVIEW TEMPLATE  (99_chapter_end.tex)     4-8 pages
=======================

\chaptersection{Chapter N Summary}
  - Key results: table  Result | One-line statement (with conditions!) | Where (\thmref)
  - Algorithms:  table  Algorithm | Time | Memory | Code (\coderef)
  - Decision guide: a figure (flowchart) from "what the tree problem looks like"
    to "which tool" (e.g. path query -> HLD; subtree query -> Euler + Fenwick;
    nearest common node -> LCA; rerooting -> tree DP).

\chaptersection{Common Mistakes Checklist}
  itemize of the chapter's traps, one line each, with the fix. For trees these are
  usually: missing \nil{} / leaf base case, depth vs height off-by-one, forgetting
  to pass the parent in a general-tree DFS (infinite loop), recursion depth on a
  skewed tree, overflow on subtree sums / 2^h counts, 0- vs 1-indexed nodes, and
  treating a forest as one tree.

\chaptersection{Quick Reference Card}
  \begin{quickref}[Chapter N at a glance]
    formulas (with conditions) + the minimal code the chapter needs, drawn as
    ASCII trees where a picture beats words.
  \end{quickref}
  (A long code listing goes after the quickref box, not inside a macro argument.)

\chaptersection{Mixed Problem Set}
  \begin{mixedset}
    \practice{...}{...}{...}{...}{hint}     -> M<chapter>.<i>
  \end{mixedset}
  5-8 problems that combine the chapter's topics and do not say which topic they use.

\chaptersection{Related Topics}
  Backward and forward links (\chref, \secref), one line each: what that chapter adds.
