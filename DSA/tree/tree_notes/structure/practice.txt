PRACTICE LIST TEMPLATE
======================

\begin{practiceset}
  \practice{<Official title>}{<Judge ID>}{<URL>}{<difficulty + badge>}{<one-line hint>}
\end{practiceset}
    -> numbered Q<chapter>.<topic>.<i> automatically
    -> difficulty argument ALWAYS ends with the plain level badge: {LC Medium L3}
       (never \lv{3} inside \practice/\practicehh/\solvedproblem arguments -- the
       xstring parsing in \difficultytag expands macros and errors; see levels.txt 2)
       (mapping and rating-verification rules: levels.txt \S1 -- official CF rating
       only, never invented; unrated problems get no badge)

HINT LADDER (optional, for the harder items)
  Give one hard item a second, stronger hint with \practicehh (six arguments --
  the five of \practice plus a second hint). Use it sparingly, on the last one or
  two items of a list, never on the easy warm-ups.
  \practicehh{<title>}{<Judge ID>}{<URL>}{<difficulty>}{<gentle nudge>}{<stronger nudge>}

RULES
- Order: easiest first. The last one or two may be harder; start their hint with
  "Stretch." and say which later section helps.
- LEVEL SHAPE: the list must step through every level band the topic reaches
  (topic covers to \lv4 -> at least one item each in \lv2, \lv3, \lv4; no 2-band
  jumps inside one list -- the ladder rule from levels.txt \S4 applies here too).
- Count: the outline's planned count minus the solved problems, at least 4 --
  a Problem Lab topic (levels.txt \S4) carries a LONGER list, 8-12 items, since
  the lab itself consumed the solved-problem budget.
- Every problem verified: it exists, the ID/title/URL are right, and it really
  practises THIS topic (a tree problem, not a graph or array problem that merely
  mentions "node").
- Prefer free judges: LeetCode, CSES, Codeforces, AtCoder, Kattis, SPOJ. Trees
  are interview-classic, so LeetCode carries a large share here.
- No duplicates across the book: search the chapters folder for the URL first.
- Hints give the first idea (which traversal, which DP state, which invariant),
  never the full solution.
- URLs must not contain % # & .

URL FORMATS
  LeetCode    https://leetcode.com/problems/<slug>/
  CSES        https://cses.fi/problemset/task/<id>
  Codeforces  https://codeforces.com/problemset/problem/<contest>/<index>
  AtCoder     https://atcoder.jp/contests/<contest>/tasks/<contest>_<letter>
  Kattis      https://open.kattis.com/problems/<id>
  SPOJ        https://www.spoj.com/problems/<ID>/

DIFFICULTY STRING
  "LC Easy" / "LC Medium" / "LC Hard"   "CF <official rating>"   "CSES"
  "AtCoder <difficulty>"   "Kattis"   "SPOJ"
