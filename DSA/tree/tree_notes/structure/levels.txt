LEVEL LADDER CONTRACT  (book-wide)  == how this book goes from basic to CF 3500+
==========================
Nothing here is optional: every problem, every solved rung and every new tool
carries a level badge, so the reader always knows where they stand and what the
next rung is.

1. THE LADDER
   Badge  Band (CF rating)     Means                                     Typical judges
   \lv{1} ~800 and below       knows what a tree IS; definitions,        LC Easy, CSES intro,
                               one-pass DFS, hand simulation             CF 800-1000
   \lv{2} ~1100-1300           standard patterns applied verbatim;       LC Easy/Medium, CF 1100-1400
                               depth/height/subtree/paths by recursion
   \lv{3} ~1500-1700           two techniques combined; state design     LC Medium, CF 1400-1800,
                               is given away by the statement            CSES tree tasks
   \lv{4} ~1900-2200           the reduction is NOT given; choice of     LC Medium/Hard, CF 1900-2300
                               traversal/state must be argued; one
                               non-obvious trick (sentinel pair return,
                               diameter via two DFS, virtual edges)
   \lv{5} ~2400-2900           chapter tool + foreign chapter tool      LC Hard, CF 2400-2900
                               (DP x tree + greedy exchange; HLD + segtree
                               beats); adversarial cases the setter hunts
   \lv{6} 3000-3500+           Div.1 D/E or equivalent: the tree is a     CF 3000+, ICPC regionals,
                               disguise; proof of the key lemma is half    IOI-style
                               the problem; multi-step reductions

   Colour = the badge's colour (setup/colors.tex lv1..lv6); it intentionally
   follows CF greys->reds so a veteran reads difficulty at a glance.
   LC-only problems: map Easy->L1-L2, Medium->L3-L4, Hard->L5-L6 BY CONTENT,
   never by label (LC Hard centroid = L4; LC Easy "Same Tree" = L1).
   CF problems: use the OFFICIAL rating shown on the problem page. Never
   invent or round a rating; unrated -> do not give it a \lv badge, mark
   "(unrated, use as stretch)".

2. TAGGING SYNTAX (everywhere)
   HARD RULE: inside the difficulty arguments of \practice / \solvedproblem /
   \practicehh the badge is a PLAIN " L3" suffix, never \lv{3} -- xstring expands
   macros and \difficultytag dies. It peels " L3" off and renders a second chip
   in the lv colour. The \lv{n} macro form is for tables, prose and ladder rungs.
   - solved problems:   difficulty string of \solvedproblem gains the badge:
       {LC Medium L3}
   - practice items:    same, in \practice/\practicehh difficulty argument.
   - ladder rungs:      the Approach column starts with \lv{n}:
       \lv{1} brute DFS & ... & $O(n^2)$ & \tle
   - subsections that are optional-at-first-reading: end the title with
       \hfill\lv{5}   (e.g. "2.4 proof via generating functions \hfill\lv{5}")

3. TWO READING PATHS (declare in EVERY opener, see theory.txt station 1b)
   Beginner path   = all L1-L3 material + every second "Recall card" self-test.
                   Skips: proofbox of \lv{5}+ results, Variations marked \lv5/6,
                   Summit, hardeningbox, and \lv5+ practice items.
   Full path     = everything, in book order.
   A chapter is "climbable" only if a reader finishing the beginner path can
   still read the L4-L6 material later without missing definitions: every
   \lv5+ section must restate (one line + \secref) the tools it needs.

4. PER-TOPIC PROBLEM LAB  (this replaces old fixed budgets; size is unlimited)
   Each topic's solved-problem set is a LAB of 10-20 problems, one per rung:
     L1-L2 warm-ups   : solved CONCISELY (statement, ladder table, code, verdict)
     L3-L4 core       : solved FULLY (all steps of solved_problem.txt)
     L5 stretch       : fully, with thinkbox showing the dead ends
     L6               : belongs to the chapter end SUMMIT, not to topics
   Rules: rungs must be consecutive in level (no L1 -> L4 jump without an L2/L3
   between); every problem still obeys the URL-once rule; the chapter's mixed
   set and checklist carry the badges too.

5. DIAGRAM OBLIGATIONS for level material (diagrams.txt enforces rendering):
   - opener: the ladder figure (six-step staircase, chapter's topics placed on
     it) -- station 1b of theory.txt;
   - every chapter-end DIFFICULTY PROGRESSION table row starts with its badge;
   - Summit solutions: >= 2 figures (the disguise BEFORE, the true structure
     AFTER the reduction);
   - thinkbox dead ends: each \deadend gets a one-line mini sketch when the
     failed idea is structural (wrong rooting, missing base case, bent path
     assumed straight);
   - WA Clinic: draw the clinic as a decision TREE figure, table only as
     backup.

6. SUMMIT SOURCING (the honest-rating rule, book map v2 per part)
   Parts IV-V (ch16+): TRUE SUMMIT = real CF 3000-3500+ rated problem, official
     rating quoted, composing >= 2 chapter tools + >= 1 earlier-chapter tool.
   Parts I-III: the reader lacks the tools for a fair 3000+ problem, so the
     Summit is SCALED: the hardest problem solvable with EXACTLY the chapter's
     tools (CF 1900-2700 / LC Hard / CSES+-class), badged with its real rating
     and marked "summit for now" plus a one-line pointer to the later chapter
     where its true \lv6 version lives (e.g. ch13 DP-I -> "the 3200-class version
     waits in ch23 beats"). NEVER inflate a rating to fill the slot.
   Unrated/exotic judges: no badge without official rating; use "classic" and
     describe difficulty by comparison to a badged problem.
