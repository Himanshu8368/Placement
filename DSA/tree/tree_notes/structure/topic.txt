TOPIC TEMPLATE  (one file = one \section)   target 20-50 pages (problem lab!), 10+ diagrams
==============

Stations, in this fixed order:
  0. previouslybox (topics 2..K only)   3 spaced-repetition questions from EARLIER
                                        topics of THIS chapter -- answers are
                                        \secref pointers, never re-explanations;
                                        make one question the chapter running
                                        example ("what did DFS return at node X?")
  1. topicintro box                     what, why in contests/interviews, prerequisites, "after this you can"
  2. recognitionbox PATTERN CARD        when to use / when NOT / keywords / one-line test
  3. \subsection{Intuition}             picture first (1+ figure), small concrete tree
  4. \subsection{Definitions ...}       definition boxes, each followed by an example or picture
  5. \subsection{<Properties>}          theorem/lemma/corollary boxes, each with a full proofbox
                                        (may be split into several subsections)
  6. \subsection{<Algorithms>}          derivation of the algorithm, lstlisting, complexitybox
  7. \subsection{Worked Examples}       example boxes / traceboxes on small trees
  8. \subsection{Variations and Twists} 3-6 one-line entries: how contests mutate this
                                        pattern ("adds X -> do Y"), each pointing at the
                                        problem or section that demonstrates it
  9. \subsection{Common Pitfalls}       warningboxes; every top-3 pitfall must show
                                        WRONG code and the RIGHT fix side by side
                                       (comparisonbox or two short lstlistings)
 10. \subsection{Problem Lab}          10-20 solved problems on the level ladder
                                        (levels.txt \S4): \lv1-2 warm-ups solved
                                        CONCISELY (statement + ladder table + code +
                                        verdict), \lv3-4 core FULLY (solved_problem.txt),
                                        \lv5 stretch fully WITH the thinkbox; levels
                                        consecutive, one URL each, difficulty rises
                                        inside the lab -- see solved_problem.txt
 11. \subsection{Practice Problems}     preceded by a stuckbox ("Stuck? Work through
                                        this list": 3-5 yes/no diagnostics specific to
                                        THIS pattern -- never generic advice), then
                                        practiceset (level-tagged), see practice.txt
 12. recallbox AT THE END               "10-second refresher": 3 lines max +
                                        \selftest{5 questions} -- the reader must
                                        answer from memory, on paper; one question
                                        must be "write the skeleton from memory"

Subsection titles may be specific ("Counting Binary Tree Shapes" instead of "Properties"),
but the order is fixed, the lab section is always called "Problem Lab", and the
file always ends with the recallbox (no \subsection around it).

THE PATTERN CARD  (station 2 -- the DP series' recognition framing)
------------------------------------------------------------------
\begin{recognitionbox}[Pattern card -- <short pattern name>]
\reckey{``<actual problem phrasing>'', ``<another trigger phrase>'' -- <one-line gist>.}
\recuse{
  \item <three concrete situations where this pattern is the right tool>
}
\recnotuse{
  \item <two or three situations that LOOK similar but need the sibling pattern,
        each pointing at the right \secref/\chref -- this is the half DP made
        famous; never leave it empty>
}
One-line test: \emph{<the single question that decides "is this my pattern?">}
\end{recognitionbox}

ANTI-REPEAT CONTRACT: the card speaks only about RECOGNITION (when/when-not/keywords).
The topicintro says what the topic IS; the intuition says WHY it works; the pitfalls
say where it BREAKS. If the card can say something that one of those covers better,
cut it from the card. Keyword lists must not copy the opener-guide rows verbatim --
here they gain the when-NOT contrast, that is the difference.

OPTIONAL TOOLS  (use where they genuinely help; NOT mandatory stations)
- analogybox[Real-world name] in Intuition: anchor an abstract idea with a picture-words
  metaphor (file system, tournament bracket, org chart, family tree). One short paragraph.
- \usedin{Chapter X (name)}{what it buys you}: forward motivation just after topicintro,
  so the reader sees the payoff before the hard part (vital for persistent/link-cut chapters).
- State-sequence figure (see diagrams.txt) whenever an operation TRANSFORMS the tree.
- \vsbox{A vs B}{A}{B}{what A is}{what B is}: kill a classic confusion (depth/height,
  full/complete/perfect, DFS/BFS, segment/Fenwick) in Definitions or Pitfalls.
- \practicehh{...}{...}{...}{...}{hint1}{hint2}: a second, stronger hint on the harder
  practice items so a learner is never stuck on a single nudge.

BOX SYNTAX
----------
Numbered (share one counter per section; label = prefix + second argument):
  \begin{definition}{Title}{c01-tree}      -> Definition 1.1.1, label def:c01-tree
  \begin{theorem}{Title}{c01-edges-nodes}  -> label thm:c01-edges-nodes
  \begin{lemma}{Title}{...}  lem:    \begin{corollary}{Title}{...}  cor:
  \begin{proposition}{Title}{...} prop:   \begin{example}{Title}{...} ex:
  Starred versions (\begin{theorem*}{Title}{}) are unnumbered.
Unnumbered, optional title in [ ]: topicintro insightbox warningbox tracebox complexitybox
  comparisonbox notebox proofbox problemstatement quickref; formulabox takes no title.
Pattern-study tools: recognitionbox[card title] with \recuse{\item..} \recnotuse{\item..}
  \reckey{keywords}; stuckbox[title] (itemize inside); approachbox{Name}{cost} (long
  solution ladders) and the compact ladder table of solved_problem.txt (short ladders);
  lastword[title] ONLY in chapter endings; verdicts \ac \tle \mle \re \ce in tables.
Self-study tools: previouslybox (start of topics 2..K, enumerate of \secref-answered
  questions); recallbox[title] + \selftest{\item..} (end of EVERY topic); attemptgate
  + \peek/\nudge/\fullhint, thinkbox + \deadend{try}{kill} + \aha{idea}, hardeningbox,
  and level badges \lv{1}..\lv{6} -- all per levels.txt.
Optional learning tools: analogybox[title] ... ; \usedin{where}{what};
  \vsbox{title}{head1}{head2}{body1}{body2} (short contrasting phrases only);
  \practicehh{title}{src}{url}{diff}{hint1}{hint2} inside practiceset/mixedset.
Useful macros: \depth(v) \height(v) \size(v) \level(v) \parent(v) \children(v)
  \lca(u,v) \dist(u,v) \diam(T) \degop(v) \leaves(T) \subtree(v) \nil
  \floor{} \ceil{} \abs{} \set{} \card{} \bigO{} \bigTheta{} \term{} \code{} \cpp
