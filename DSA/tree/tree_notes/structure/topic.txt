TOPIC TEMPLATE  (one file = one \section)        target 8-14 pages, 6+ diagrams
==============

Stations, in this fixed order:
  1. topicintro box                     what, why in contests/interviews, prerequisites, "after this you can"
  2. \subsection{Intuition}             picture first (1+ figure), small concrete tree
  3. \subsection{Definitions ...}       definition boxes, each followed by an example or picture
  4. \subsection{<Properties>}          theorem/lemma/corollary boxes, each with a full proofbox
                                        (may be split into several subsections)
  5. \subsection{<Algorithms>}          derivation of the algorithm, lstlisting, complexitybox
  6. \subsection{Worked Examples}       example boxes / traceboxes on small trees
  7. \subsection{Common Pitfalls}       warningboxes
  8. \subsection{Solved Problems}       2+ problems, see solved_problem.txt
  9. \subsection{Practice Problems}     practiceset, see practice.txt

Subsection titles may be specific ("Counting Binary Tree Shapes" instead of "Properties"),
but the order is fixed and the last two subsections are always
"Solved Problems" then "Practice Problems".

OPTIONAL TOOLS  (use where they genuinely help; NOT mandatory stations)
- analogybox[Real-world name] in Intuition: anchor an abstract idea with a picture-words
  metaphor (file system, tournament bracket, org chart, family tree). One short paragraph.
- \usedin{Chapter X (name)}{what it buys you}: forward motivation just after topicintro,
  so the reader sees the payoff before the hard part (vital for persistent/link-cut chapters).
- State-sequence figure (see diagrams.txt) whenever an operation TRANSFORMS the tree.
- \vsbox{A vs B}{A}{B}{what A is}{what B is}: kill a classic confusion (depth/height,
  full/complete/perfect, DFS/BFS, segment/Fenwick) in Definitions or Pitfalls.
- \practicehh{...}{...}{...}{...}{hint1}{hint2}: a second, stronger hint on the harder
  practice items so a learner is never stuck on a single nudge.

BOX SYNTAX
----------
Numbered (share one counter per section; label = prefix + second argument):
  \begin{definition}{Title}{c01-tree}      -> Definition 1.1.1, label def:c01-tree
  \begin{theorem}{Title}{c01-edges-nodes}  -> label thm:c01-edges-nodes
  \begin{lemma}{Title}{...}  lem:    \begin{corollary}{Title}{...}  cor:
  \begin{proposition}{Title}{...} prop:   \begin{example}{Title}{...} ex:
  Starred versions (\begin{theorem*}{Title}{}) are unnumbered.
Unnumbered, optional title in [ ]: topicintro insightbox warningbox tracebox complexitybox
  comparisonbox notebox proofbox problemstatement quickref; formulabox takes no title.
Optional learning tools: analogybox[title] ... ; \usedin{where}{what};
  \vsbox{title}{head1}{head2}{body1}{body2} (short contrasting phrases only);
  \practicehh{title}{src}{url}{diff}{hint1}{hint2} inside practiceset/mixedset.
Useful macros: \depth(v) \height(v) \size(v) \level(v) \parent(v) \children(v)
  \lca(u,v) \dist(u,v) \diam(T) \degop(v) \leaves(T) \subtree(v) \nil
  \floor{} \ceil{} \abs{} \set{} \card{} \bigO{} \bigTheta{} \term{} \code{} \cpp
